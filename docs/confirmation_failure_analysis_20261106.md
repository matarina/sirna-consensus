# 本轮失败原因与后续调整

本轮已经完成架构、候选训练与严格确认流程。没有满足独立确认门槛，默认模型没有替换。
以下区分可直接证明的问题与需要进一步检验的解释。

| 观察 | 可支持的判断 | 调整方法 |
| --- | --- | --- |
| 合格独立确认 ID 为 0 | 无法计算可信的独立增益、置信区间或新生成候选收益。这是本轮晋升的直接阻断原因 | 在下一轮拟合前，取得至少两个此前未用于训练、选择或查看结果的研究；固定来源、完整分子、实验条件、基因与序列隔离审计，再独立预注册。当前不下载、不替换旧资格 |
| Huesken 25 基因、单一研究；开发 NDCG@5 = 0.786830 | 本轮开发诊断未超过 0.80，但它不能估计独立确认成绩，也不能与旧四研究 OOF 数字直接比较 | 保留当前预注册搜索结果，不为跨越阈值追加配置。后续新开发轮可在 Huesken 内预注册更多特征/模型；不能使用外部确认成绩指导调整 |
| 开发 Top3 命中率为 1.0 | Top3 指标可能存在天花板；Huesken 随机 Top3 解析期望已达 0.845476。不能据 Top3 单独宣称跨基因泛化 | 优先使用预注册的宏平均 NDCG、同候选池基线、配对置信区间与预算收益；保留 Top3 作为次指标 |
| 开发 P@5 = 0.896，随机期望为 0.510186；随机 NDCG@5 = 0.456472 | 在开发数据上存在排序信号；这只是描述，不能作为独立性能提升或晋升证据 | 这些解析随机结果不参与选择，也不改变本轮门槛。实现保留在 `development_diagnostics.py` |
| 最终模型为 452 特征的浅层梯度提升树；不同外折选择不完全相同 | 模型选择对训练子集有变化；不能据此确定生物学原因 | 下一轮可预注册模型稳定性与特征消融，仍仅在 Huesken 内执行；需要独立确认后才能替换默认 |
| 真实生成面板缺少可匹配的独立全双链活性 | 排序验证不能替代生成效力验证。未知突出端、修饰或 passenger 不能通过同 19mer 继承活性 | 仅按相同实验条件、完整 guide/passenger/overhang/已知 chemistry 精确计分；未知保持未知，收益给出配对保守界限 |
| BCL2L1 工程运行：2,553 个候选，研究与筛查面板均完成 5/5 | 证明本地模型接口、完整人参考筛查与输出工程流程可运行；该转录本此前已暴露 | 仅记录为工程集成，不能作为独立完成率无损或活性收益证明 |
| 多研究 LOSO 与 Huesken-only 训练冲突 | 在本轮约束下真正的多研究 LOSO 不可执行 | 明确标记不可用；不拿外部逐研究评分冒充 LOSO。未来如需多研究开发，须先变更开发策略并预留全新的独立队列 |

已实施的改进包括：Huesken-only 训练入口、折内加权与预处理、三类模型的固定嵌套选择、基因/正反向 Hamming≤2/17mer 连通组隔离、不可覆盖的评估产物、哈希冻结、独立算术重算、未知活性和实际预算收益界限、失败即保留默认。

没有足够证据将尚未达到独立门槛归因于特定序列特征、细胞系或某个模型家族。单研究与实验体系差异是泛化的限制，不能在没有新独立数据时声称是已证实的因果解释。
