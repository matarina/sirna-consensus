How to read this

Agreement is counted at the site level, not the string level: the tools emit different lengths and offsets for the same duplex, so candidates within offset_tolerance and sharing all but 2 bases are grouped. The default grouping is bounded (an anchored cluster, not a transitive chain). Votes are distinct generator tools; SIREN is an evaluator and does not add a design vote. Sequence/specificity filters are applied after voting. The order-ready file is top_guides.fa; every candidate, including rejected ones, is in all_candidates.fa.

Limitations

  • Consensus votes are generator-tool votes. SIREN is an evaluator; its enumeration hits and input-only fallback are not design votes.
  • Specificity is separate evidence. A transcriptome-backed SIREN screen with off-targets is a hard eligibility failure; input-only or failed screens are not transcriptome-wide claims.
  • Site-level consensus uses bounded offset clustering by default; exact identity and fuzzy single-linkage modes are explicit choices.
  • Top-K enforces min_votes. Singleton sites remain in candidates.tsv and all_candidates.fa for inspection, not in the order-ready set.
  • A tool that returns only its own Top-N cannot be distinguished from one that filtered a site out.
  • No wet-lab confirmation; tool scores are not comparable across tools.
  • Off-target scope is whatever each tool was given, unless a shared transcriptome was supplied.
