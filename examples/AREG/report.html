How to read this

Agreement is counted at the site level, not the string level: the tools emit different lengths and offsets for the same duplex, so candidates within 2 nt and sharing all but 2 bases are treated as one site. A candidate's vote count is the number of distinct tools that proposed it. Sequence filters (GC window, homopolymer, complexity, guide 5′ end, internal palindrome) are applied after voting, so no single tool decides what survives.

Limitations

  • Site-level consensus, not sequence-level intersection: tools emit different lengths and offsets for the same duplex.
  • A tool that returns only its own Top-N cannot be distinguished from one that filtered a site out.
  • No wet-lab confirmation; tool scores are not comparable across tools.
  • Off-target scope is whatever each tool was given, unless a shared transcriptome was supplied.
