03 / ARCHITECTURE & TOOLS

详细架构：自研主流程、外部工具与验证支路

当前入口为 sirna-consensus run --profile rna19p2。Python 主流程负责候选穷举、分子身份、模型调用和面板选择；外部工具以独立子进程运行。下面按真实调用顺序展开，默认行为、可选功能和历史实验分别标注。

先区分三件事：注册了某个工具，不代表本次运行调用了它；工具能运行，不代表已经证明有效；工具同意一个位点，不代表它们生成了同一个完整双链。本轮 Katoh 实验明确 tools=[]，只测试冻结模型和自研完整双链生成，没有运行 siRNAdesigner、siRNAforge、SIREN 或转录组筛查。

主流程：8 个执行节点

01 / fasta.py · pipeline.py输入、配置与追踪

单条 transcript FASTA → U/T 标准化、坐标轴与 SHA256。解析 profile、工具名单、scorer / reference 清单，生成内容派生 run_id；模糊碱基窗口跳过，不改成 A。

02 / selection.enumerate_duplexes自研完整分子穷举

23 nt 目标上下文 → 19 bp 配对区 + 两端各 2 nt 突出端；guide / passenger 各 21 nt。内部构造 RNA19+2，不依赖外部工具是否给出候选。边缘缺侧翼不补造。

03 / tools.* · normalize.py外部意见，可选并行

siRNAdesigner / siRNAforge 为 generator；SIREN 为 evaluator。最多按 jobs 并行子进程，记录 command / version / ok、empty、failed、unavailable 与原始输出。

04 / types.Core · attach_evidence身份规范化与证据挂接

核对原始完整双链与 1-based 坐标，保存 chemistry / molecule_id。已知化学域且完整分子相同才算 exact molecule；同位点只保存 site evidence。SIREN 不进入 generator 投票。

05 / filters.py · scoring.py规则标记与冻结评分

GC、同聚物、低复杂度、回文和 seed 风险标记；soft 默认只注释。scorer 校验模型及输入哈希，仅将配对 antisense 19-mer 输入模型，输出连续排序分数。

06 / screening.py + Bowtie可选转录组筛查

显式 --screen-manifest / --target-gene 触发 Bowtie：两个配对方向、0/1/2 mismatch 基因负担；另算 7-mer seed 与 3′UTR 的基因负担及 isoform 覆盖。

07 / selection.rank_candidates · panels排序、间距与弃权

auto 读取默认 policy → 模型百分位排序；没有默认模型时按 quality。TopK=5、最小间距30 nt、同 guide 去重。research / diverse / screened 面板分别输出。

08 / design.py · JSON / TSV / HTML输出与复现

run.json 保存配置、工具状态、哈希与逐候选证据；candidates.tsv、research_top.fa、diverse_top.fa、screened_top.fa、report.html。未筛查不记为 pass。

工具 / 角色方法与输入输出在当前 v3 的位置本地探测与本轮使用
siRNAdesigner
sirnadesigner · generator
上游项目		Python 规则扫描；GC、重复序列、末端偏好等。输入 transcript FASTA，输出 CSV 的 guide / passenger 与规则分数；adapter 从原始 24 nt 上下文恢复 19 bp + 两个 2 nt 突出端。额外的规则设计意见；位点证据与精确分子支持分开保存。不能用“通过规则”替代效力或 off-target 实验。当前 scorer 环境可用，脚本以 SHA256 标识；Katoh：未调用。
siRNAforge
sirnaforge · generator
上游项目		Docker / OCI 内执行 sirnaforge design；上游使用 ViennaRNA 等热力学相关信号。adapter 保存 composite_score、原始序列与位置；当前调用显式 --modifications none --overhang ''。其原始输出格式可能与主流程 RNA19+2 不同；只匹配位点不算完整分子投票。输出中的“21 nt”不能自动解释成“19 bp+2 nt overhang”。可选脱靶计数未配置时不能当作已运行。本地镜像可用：sha-4c05e4b，运行固定到实际 image ID；Katoh：未调用。
SIREN / RNAhybrid
siren · evaluator
上游项目		SIREN 调用 RNAhybrid 评估 21-mer。需输入目标和 transcriptome；adapter 区分 input_only、transcriptome_screened 与失败。独立评估器，不投 generator 票；当前 design.py 只将 generator 输出挂到候选证据，SIREN 的结果/状态单独留痕。不是 v3 Bowtie 筛查的别名，也不是模型特征。本次 scorer 环境探测未找到 PATH 入口；可通过 SIREN_BIN 指定。不能据此断言其他环境未安装。Katoh：未调用。
Bowtie 1.3.1
v3 reference screen		对两个配对方向运行 bowtie -f -v 2 -a --norc；基因映射来自固定 GENCODE / HGNC 清单。另用自研 seed 索引统计 3′UTR 7-mer 负担。未预期基因上 0 或 1 mismatch 命中触发 reject；2 mismatch 和 seed 负担是 advisory，不单独作为硬拒绝阈值。缺少 intended hit / 映射完整性则 unverified。历史 BCL2L1 / HIF1A 工程运行使用；必须显式配置参考。Katoh：未调用。

当前实际默认模型

scikit-learn HistGradientBoostingRegressor

models/default_policy.json → development_20261106/scorer_manifest.json → 已冻结 model.pkl。

100 维 sequence_v1：19×4 位点 one-hot、4 个碱基比例、16 个 dinucleotide 比例，以及整体 GC、seed GC、两端 GC 差、最大同聚物长度。最终 depth=2、min_leaf=10、L2=1。不读取 assay 标签，也不读取工具分数或 RNAhybrid 能量。
