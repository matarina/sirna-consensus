审查结论

按“measured-candidate scorer-only”标准，当前 pipeline 在 6 个 measured-candidate/scorer-only benchmark 上达标：UBE2H、Reynolds、Vickers、Ui-Tei、Khovorova、siRNAEfficacyDB 子集。

但这不是完整生成 pipeline 的通用证明。 UBE2H 的完整 `run` 因生成器 format 与实测 `passenger_unknown` 不匹配，candidate coverage = 0；Sciabola 旧 +3.8 pt 来自 multidose 平均标签，按论文端点重建后 +1.1 pt、CI 跨 0；历史 LO-GO 值不能由单一 checkpoint 复现；Shabalina、Martinelli 的 19-mer/修饰格式不达标。

一句话： 计算层面可辩护的是“OligoFormer 在 measured candidates 上的排序富集”；完整生成、独立外部验证和生物/临床层面仍不可辩护。

3. 达标判定

我使用的标准是：

  • candidate_coverage >= 0.9
  • paired gene-level Top-5 difference vs random >= +10 pt
  • bootstrap CI lower bound > 0
  • AUROC > 0.5
  • 至少 5 个基因/study；单基因 case 单独标注

达标

UBE2H、Reynolds、Vickers、Ui-Tei、Khovorova、siRNAEfficacyDB 子集；5-study holdout composite 也达标。

不达标 / 无效

Shabalina（CI 含 0）、Martinelli（CI 含 0）、Harborth（无 enrichment）、UBE2H 完整生成（coverage 0）、Sciabola（+1.1 pt，CI 跨 0；非 LO-GO 复现）。

4. 当前 pipeline 的调整

  • 默认 selector = OligoFormer。 不保留额外的 21-mer CNN 路径。
  • 按 format 路由： passenger_unknown 19/21 → OligoFormer model；modified passenger21-overhang2 → native/quality。
  • 加 coverage gate： coverage 低时标为 measured-candidate replay/scorer-only，不能声称完整生成 pipeline 性能。
  • 补 LO-GO 与校准： 若要证明 Sciabola 的 LO-GO，需要每折重训并保存模型、做 calibration/Brier/不确定性；但 LO-GO 会使用 Sciabola 其他基因的训练标签，不能当作无泄漏独立外部验证。
  • SIREN 暂不可用： 当前没有 SIREN/RNAhybrid 与 transcriptome；它只影响 specificity，不会自动提高 efficacy Top-5。
  • Shabalina/Martinelli 不作为 efficacy 达标集： 适合格式/覆盖审计；若要达标需重训或扩大样本。

5. 限制

证据层面

多数结果是 measured-candidate scorer-only；不是完整生成 pipeline。Sciabola 当前 frozen held-out 是 measured-candidate replay；LO-GO 历史值是同一数据集内跨基因验证，不是独立外部验证。UBE2H 只有 1 个基因；Shabalina/Martinelli 样本小或格式不匹配。

工程层面

scoring.py 契约已修复：只接受 paired_antisense_19，移除未声明的 binding21 子 core 分支并拒绝 guide21 约定；新增 canonical binding19 + 2-nt overhang 测试，全量 pytest 通过。development_freeze.json 已重建并通过 verify。因 scoring.py 变更，final_freeze.json 现在是 stale；本环境缺少 pin 的 sirnaforge-platform scorer 资产，无法重切，需在具备这些资产的环境 recut；当前保留该 lock 不动。selection.json 仍写 independent_validation_passed=false。
