当前可以支持的结论

推荐 Wang 作为主要回顾性排序 benchmark，Filhol 作为补充挑战集。在已测候选池内，模型 Top5 命中率分别为 97.1% 和 74.0%。完整生成流程已运行，但实际生成 Top5 的实测覆盖不足，目前无法证明新设计的效力或完整 pipeline 的优越性。

两项研究均有同行评审的原始实验、多个内源性靶基因和可核验补充数据。这里的“权威”指实验来源可信、方法与序列可追溯；没有依据把它们称为官方标准或公认金标准。研究质量、与本 pipeline 的兼容性、是否发生数据泄漏，是需要分别核查的问题。

1. 为什么选择这两份原始实验数据

来源的可信依据与用于本 pipeline 的理由
数据集原始实验与质量依据与本 pipeline 的关联必须保留的限制
Wang et al., 2009
Nucleic Acids Research 37:e152		独立于该论文训练数据的 140 条验证记录，覆盖 14 个 HeLa 内源性基因；作者报告双盲、随机实验顺序。每基因包括新算法、旧算法及随机位置设计；同批合成，两个实验日、三次转染重复与重复 PCR，每条共 12 次 knockdown 测量。Supplementary Table S3 提供 guide、passenger 及 3 / 30 nM 剩余 mRNA；可核查双链身份，并在固定剂量下评估 TopK。作者也开发了被比较的算法，不能视为对本 pipeline 的第三方盲测。面板混合预选与随机设计；passenger 的 dTdT 化学身份需单独保留。
Filhol et al., 2012
PLOS ONE 7:e48057		10 个内源性癌症相关基因；HeLa 20 nM 条件下用 qRT-PCR 测定；两个内参、独立生物实验与重复测量，含阳性和阴性对照。S1 发布两条链，S3 发布逐条实验数据；21 nt、19 bp 配对区加 2 nt 悬垂，与当前 designer / scorer 的常规 siRNA 格式接近。候选按 DSIR 高分预选，不能代表转录本上所有位置。正文称 128 条，S1 / S3 实际均有 129 个唯一实验 ID；须按原表审计。

推荐依据是原始实验设计、可追溯序列与当前任务的适配程度。期刊名称只提供发表背景；两份论文均未验证本 pipeline，也未对其任何新设计提供效力背书。这两项实验支持常规细胞转染 siRNA 的回顾性评估，不能直接外推到体内递送或任意修饰化学体系。

原论文：Wang 全文与实验方法；Filhol 全文与补充材料。Wang 使用 S3 验证面板，不使用该论文开发模型时分析的 Huesken 数据。

Wang 主端点：3 nM，knockdown = 100 − percent mRNA remaining；30 nM 仅作预设敏感性分析，不跨剂量平均。相同 duplex 的重复观察在各剂量内分别取算术均值。Filhol 主端点：S3 最后一列 “%silencing (from statistical model)”，直接按 knockdown 读取；不把 DSIR 预测分数当作实测效力，也不按性能选择列。另一 dilution-series 列的文字说明存在歧义，未用于主结论。

Filhol 使用与原始表中长度一致、全部 129 个配对核心均可唯一映射的历史 RefSeq；当前 RefSeq 的变更曾造成三个 CSNK2B 位点缺失。Wang 按预先固定的 RefSeq 映射，保留六条未映射记录及原因。全部原始记录、排除项、转录本和文件 SHA256 可从产物核查。

对原始 269 条记录的 guide 配对 19-core，在正向与反向互补两种方向上，与公开 Hu2361 / Mix472 / Taka702 的 Hamming ≤ 2 匹配数均为 0。与此前已使用 Sciabola 核心匹配的五条记录已排除；两份新面板之间无 Hamming ≤ 2 匹配。更保守的连续 17-mer 位移重叠排除及整基因 HIF1A 排除另行报告。

这项审计限定于已固定的参考序列。完整上游 checkpoint 训练与模型选择谱系尚未独立证明，因此不能写“保证完全无泄漏”或“从未见过这些基因”。本次未拟合或调参，使用原始冻结 checkpoint，未使用 Sciabola 适配模型或外部结果选出的 selector policy。已查看这些结果后，再据此调整的流程需要新的封存测试或前瞻实验。

8. 根因与优先调整方法

当前证据指向的阻塞点
问题本次证据建议调整
分子格式与投票不兼容designer 输出 19+2，forge 输出 blunt21；两项研究均无 ≥2 工具支持的精确分子，默认两票输出为空。先定义共同的分子格式、悬垂来源与化学身份；或把 site agreement 单独作为证据特征，保留原分子身份。不得把异构分子算作同一 duplex 票。
生成 / 模型支持覆盖不足冻结模型仅能打分约 11–12% 的生成分子；Wang 已测完整 duplex 召回仅 2/127。增加明确的 19+2 候选生成模式，考虑覆盖所有合规 target windows，再把生成器评分作为特征。改变 blunt21 的配对区或悬垂会产生新分子。
硬过滤损失有效分子在已测池内，Filhol 与 Wang 分别有 14 与 37 条有效 duplex 不满足当前硬规则；其中部分原本也未被生成。在独立开发集比较 hard 与 soft，并约束 TopK 完成率；统一原始 run 的硬过滤与 select 的 soft 标注口径。
排序增益和跨实验适用性仍有限Wang 已测排序有用，Filhol 较脆弱；两项 model − native 的 CI 都跨 0。保留冻结模型与简单规则基线；如需训练，用独立开发数据并按基因 / study / 序列近邻分组嵌套验证。若修正上游 LSTM 布局，须重新训练验证。
缺少新设计的实验标签没有任何基因的实际生成 Top5 被完整测量。冻结调整后流程，在多个新基因上合成实际 Top5；固定剂量、化学与转染条件，对比同预算基线和随机设计。历史未测候选不能补成阴性。

本次没有完成可验证的转录组脱靶筛查，因此效力结果不提供脱靶特异性结论。上述调整是后续开发方向；当前报告没有在这两个面板上调参，也不把看过标签后的流程修改称为新的独立测试。
